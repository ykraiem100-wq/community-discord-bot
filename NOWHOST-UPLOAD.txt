DOS COMMUNITY — رفع الحزمة النظيفة على Nowhost
================================================

1) فك ضغط ملف community-discord-bot-fixed.zip (النسخة المعدّلة).
2) افتح مجلد community-discord-bot-main الموجود داخل الملف المضغوط.
3) ارفع محتويات هذا المجلد إلى جذر مشروعك في Nowhost؛ يجب أن يكون package.json بجانب مجلدي src و assets.
4) اختر Node.js 20.x.
5) أمر التثبيت: npm install
6) أمر التشغيل: npm start
7) احتفظ بمتغير DATA_DIR الحالي الذي يشير إلى التخزين الدائم، مثلاً /app/data.

تتبّع الدعوات: امنح البوت صلاحية Manage Server لقراءة استخدام روابط الدعوة وتحديد صاحب الدعوة. ولأمر .رابط امنحه Create Instant Invite في قناة إصدار الرابط. يبدأ العد من وقت تفعيل التتبع ولا يستعيد الدعوات القديمة.

متغيرات البيئة المطلوبة موضحة في .env.example:
DISCORD_TOKEN, DISCORD_CLIENT_ID, DISCORD_GUILD_ID (اختياري),
OWNER_ID (اختياري), BOT_PREFIX, DATA_DIR, TZ.

المتطلبات التي أضيفت في هذه النسخة:
- إصلاح تشوه صور المتجر والقوانين: النصوص العربية والأوامر تظهر الآن داخل Discord Embeds، والصور تُرفق داخل الـEmbed مباشرة بدلاً من رسم النصوص العربية داخل Canvas.
- تم توحيد الواجهة إلى السماوي الفاتح والفضي بدلاً من الأحمر والأصفر، مع إطار متجر فضي/سماوي يحمل شعار السيرفر الحقيقي وعنوان CREDITS SHOP.
- لوحة الإدارة الرئيسية تعرض الأوامر والخيارات الحقيقية فقط، ولا تضيف قسماً أو أوامر SXP؛ وأمر .اوامر / .مساعدة يرسل قائمة الأوامر مع صورة.
- مستويات XP تصاعدية: 100، 150، 250، 400، 500، 600 لأول ستة مستويات، ثم 750 للمستوى 7 مع تصاعد متزايد بعد ذلك. يمكن تعديل المنحنى من /admin-panel.
- /add-coins و /add-xp لإدارة رصيد العضو وخبرته، و /reset-member لإعادة الضبط بعد ضغط زر التأكيد.
- يمكن تحديد قناة إشعارات اللفل من /admin-panel → العملات والمستويات، أو باستخدام .تعيين_قناة لفل #القناة. إذا لم تحددها، تُرسل إشعارات اللفل الكتابي في قناة الرسالة التي رفعت المستوى.
- رسالة الترحيب الجديدة تستخدم شعار السيرفر واسمه وتوقيع المالك تلقائياً مع أزرار Server Rules وRead Information وRoles وSocial Media وApply وNew وArena. عدّل النصوص من /admin-panel → اللوحات والرسائل.
- عنصر Colors يُنشأ تلقائياً متوقفاً. من /admin-panel → إدارة المتجر افتحه، حدد سعراً موجباً مثل coin:250، احفظه ثم فعّله. يجب إنشاء رتبة Member ورفع رتبة البوت فوقها ومنحه Manage Roles. اختيار اللون يعرض عجلة كاملة مع إدخال HEX، إضافة إلى قائمة ألوان جاهزة.

مهم جداً:
- لا ترفع ملف .env حقيقياً أو أي Discord token إلى GitHub أو داخل ZIP.
- لا ترفع قاعدة بيانات فارغة فوق قاعدة بيانات الإنتاج.
- لا تحذف /app/data أو community.sqlite؛ فهما يحتويان بيانات الأعضاء والاقتصاد.
- لا تغيّر أسرار Nowhost الحالية.
- الحزمة لا تتضمن DISCORD_TOKEN ولا قاعدة بيانات الإنتاج.
- لا حاجة لتحديث discord.js؛ المشروع يبقى على discord.js 14.28.1 وNode.js 20.x.

الفحوصات:
- فحص صياغة JavaScript: npm run check
- الاختبارات: npm test (بعد اكتمال npm install)

--- New member welcome message ---
After deploying, open /admin-panel → ترحيب الأعضاء الجدد. Select the public chat channel, edit the small-text message and its emoji button, then use إرسال تجربة. The default text is `🌟 First message from {user}`; supported placeholders are `{user}`, `{username}`, and `{server}`. Enable Server Members Intent in the Discord Developer Portal and grant View Channel, Send Messages, and Add Reactions permissions.
