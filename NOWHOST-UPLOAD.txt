DOS COMMUNITY — رفع حزمة DOS COMMUNITY المحدّثة على Nowhost
================================================

1) فك ضغط ملف community-discord-bot-events-tasks-update.zip.
2) افتح مجلد community-discord-bot-main الموجود داخل الملف المضغوط.
3) ارفع محتويات هذا المجلد إلى جذر مشروعك في Nowhost؛ يجب أن يكون package.json بجانب مجلدي src و assets.
4) اختر Node.js 20.x.
5) أمر التثبيت: npm install
6) أمر التشغيل: npm start
7) احتفظ بمتغير DATA_DIR الحالي الذي يشير إلى التخزين الدائم، مثلاً /app/data.

إعداد لوحة الإدارة:
- استخدم /admin-panel لفتح لوحة التحكم. تظهر الرسالة علناً في القناة، لكن الأزرار والعمليات الإدارية لا تعمل إلا للأعضاء المخولين.
- من القسم «صلاحيات الإدارة وروم اللوحة» اختر رتبة الإدارة الإضافية، ثم اختر روم لوحة التحكم. بعد ذلك يجب تشغيل /admin-panel من الروم المحدد.
- Administrator و OWNER_ID يبقيان مخولين. إلغاء تحديد الرتبة أو القناة يعيد السلوك الافتراضي.

المتجر والألوان:
- DOS SHOP يعرض شعار DOS داخل الإطار الفضي/السماوي، مع عنوان DOS SHOP ونص فرعي قابل للتعديل من «إدارة المتجر → إعداد القنوات → تعديل كتابة صورة المتجر».
- عنصر Colors يُنشأ تلقائياً متوقفاً. من إدارة المتجر حدّد سعراً موجباً ثم فعّله.
- بعد شراء Colors يختار العضو من عجلة مرئية وقائمة ألوان بأسماء عربية؛ لا يحتاج إلى كتابة HEX. رتبة اللون صالحة 30 يوماً ثم يحذفها البوت تلقائياً.
- أنشئ رتبة Member (أو Members / عضو / الأعضاء)، وارفع رتبة البوت فوقها وامنحه Manage Roles.

الغرف الصوتية الخاصة:
- عند تسليم منتج غرفة صوتية ينشر البوت لوحة تحكم داخل دردشة الروم الصوتي.
- يستطيع مالك الغرفة تغيير الاسم وحد الأعضاء، إضافة أو إزالة عضو، وقفل الدخول على الأعضاء المضافين أو إعادة فتحه لهم.
- يحتاج البوت إلى Manage Channels وإلى صلاحيات View Channel وSend Messages وRead Message History في الروم.

رسالة دخول الأعضاء:
- من /admin-panel → ترحيب الأعضاء الجدد اختر القناة، عدّل النص والإيموجي، وجرّب الرسالة.
- يستخدم البوت تنسيق Discord الصغير -#، والمتغيرات {user} و{username} و{server}.
- فعّل Server Members Intent في Discord Developer Portal، وامنح البوت View Channel وSend Messages وAdd Reactions.

تتبّع الدعوات: امنح البوت Manage Server لقراءة استخدام روابط الدعوة وتحديد صاحب الدعوة. ولأمر .رابط امنحه Create Instant Invite في قناة إصدار الرابط. يبدأ العد من وقت تفعيل التتبع ولا يستعيد الدعوات القديمة.

مهم جداً:
- لا ترفع ملف .env حقيقياً أو أي Discord token إلى GitHub أو داخل ZIP.
- لا ترفع قاعدة بيانات فارغة فوق قاعدة بيانات الإنتاج.
- لا تحذف /app/data أو community.sqlite؛ فهما يحتويان بيانات الأعضاء والاقتصاد.
- لا تغيّر أسرار Nowhost الحالية أو قيمة DATA_DIR الحالية.
- الحزمة لا تتضمن DISCORD_TOKEN ولا قاعدة بيانات الإنتاج.
- لا حاجة لتحديث discord.js؛ المشروع يبقى على discord.js 14.28.1 وNode.js 20.x.

الفحوصات:
- فحص صياغة JavaScript: npm run check
- الاختبارات: npm test (بعد اكتمال npm install)

الأسئلة والمهام ومكافآت الدعوات:
- من /admin-panel → سؤال اليوم العشوائي: فعّل النظام، اختر قناة، وعدّل جائزة DOS Coin. يوجد بنك 110 أسئلة عربية، وينشر سؤال واحد يومياً بين 10:00 و22:59 حسب توقيت Asia/Amman.
- من /admin-panel → المهام اليومية والأسبوعية: أنشئ مهمة يومية أو أسبوعية. اكتب xp:5000 لتجميع XP، أو messages:3 لاحتساب 3 رسائل في قناة تختارها من تفاصيل المهمة، أو manual:1 لمهمة تحتاج إثباتاً وموافقة الإدارة. اختر coins:100 أو xp:500 للجائزة. حدّد عدد الفائزين من تفاصيل المهمة. الأعضاء يستخدمون .مهامي.
- المهام اليدوية مثل حضور فيلم تحتاج إرسال إثبات ثم مراجعة الإدارة؛ لا يستطيع البوت التحقق تلقائياً من مشاهدة محتوى خارج Discord.
- من /admin-panel → مكافآت الدعوات: اكتب coins:10 أو xp:250 أو 0 لإيقاف المكافأة. تُصرف مرة واحدة عند نجاح تعرّف البوت على رابط الدعوة وتسجيل العضو. يحتاج البوت إلى Manage Server.
- اختصار المحفظة الجديد: .r وهو بديل عن .محفظتي.
- يمكن تعديل وصف المهمة وهدفها ودوريتها ونوع الجائزة ومقدارها من زر «تعديل المهمة والجائزة» داخل تفاصيل المهمة؛ وعدد الفائزين من زر مستقل.
- إذا توقف البوت أثناء نشر سؤال اليوم، يحاول إعادة نشر السؤال نفسه عند عودة التشغيل بدلاً من فقدانه.
