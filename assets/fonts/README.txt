Fonts used by the PNG renderer:
- NotoSansArabic-Regular.ttf / NotoSansArabic-Bold.ttf: Arabic text.
- NotoSans-Regular.ttf / NotoSans-Bold.ttf: Latin letters, numbers and mixed Arabic/English labels.

All font files are distributed under the SIL Open Font License. See OFL-LICENSE.txt.
The renderer loads these files directly from this folder, so Arabic and Latin glyphs do not depend on fonts installed by the hosting provider.
