DOS COMMUNITY — ACTIVE RUNTIME TEMPLATES
========================================

These nine visual/runtime templates are loaded directly by src/render.js. Keep the exact filenames.
They contain no sample user balances or product prices; the bot draws the live information on top.

dos-community-banner.png  -> DOS COMMUNITY banner/logo used on all rendered PNGs
wallet-base.png          -> /wallet and .محفظتي
leaderboard-base.png     -> /top and TOP
shop-base.png            -> DOS SHOP (three products per row; up to nine per page)
main-panel-base.png      -> public five-button server panel
content-panel-base.png   -> rules, server info, role-notification and event image messages
level-system-base.png    -> server-system / level-stage infographic
admin-dashboard-base.png -> /admin-panel home image
admin-shop-base.png      -> administration image for DOS SHOP management

The user-supplied full reference screenshots and detailed crops are in assets/design-references/.
The actual text, member avatar, balances, XP, ranks, product images and prices are populated at
runtime. The templates are backgrounds only and can be replaced by same-size PNG alternatives.
